# Card artwork

The four `*-wallet.png` assets are deterministic crops of Apple Wallet screenshots provided by the project owner on 2026-09-09. No AI-generated artwork or retyped brand marks.

- Nubank Gold Mastercard
- Flash Benefícios Visa
- Itaú Platinum Mastercard
- PicPay Mastercard (until 2026-10-21; see below)

Personal card digits and original metadata were removed. Display-P3 screenshots were converted to sRGB for web use. Surrounding phone UI is excluded. The colored glow is applied by the component, not baked into the PNG.

Bank and network marks belong to their respective owners. This does not assert an open-source license for those marks.

`pix-wallet-ui.png` is not a screenshot. It is generated by
`scripts/build-pix-card.mjs`: a teal tile with the Pix symbol taken from
`public/logos/pix.png`, downloaded from the Banco Central do Brasil's official
Pix brand assets. The script decodes that file, crops it to the symbol and
recolours it white — the same three steps the component used to perform on
every render, now done once. The symbol is not redrawn and the original file
remains unmodified; re-run the script if it is ever replaced.

`public/logos/picpay-ui.webp` comes from `public/logos/picpay.png`, the
official PicPay logo supplied by the project owner on 2026-09-30: the light
symbol is turned into a mask, filled with the logo's own green on a
transparent background, cropped to the symbol and resized to 64px high.
Not redrawn.

`public/logos/itau-app.webp` comes from `public/logos/itau.png`, the official
Itaú logo supplied by the project owner on 2026-10-08: the orange rounded
square with the "itaú" letters cut out. Only the letters are filled white
(the transparent pixels not connected to the image edge, composited over
white); the corners stay transparent. Resized to 192px. Not redrawn. It
replaced `itau-ui.webp` (the orange wordmark alone) and has a new name so
cached copies of the old file are not served.

`picpay-wallet.png` / `picpay-green-wallet-ui.webp` (2026-10-21) replace the
black PicPay card. Built from a picture of the green PicPay Platinum card
supplied by the project owner: the "platinum" text, the chip and the
contactless symbol were left out; the PicPay logo and the Mastercard symbol
were cut from that picture (mask against the card's green, not redrawn) and
placed in the horizontal layout of the other cards, on the card's own green
(#4FB273) with light grain. New filename so cached copies of the black card
are not served.
